# Playground

Change the settings or edit the snapshot, and see the tokens right away. It runs the same converter as the plugin, the CLI and the library, in your browser: nothing is uploaded.

The sample is a small design system with three collections, light and dark modes, aliases and a few styles. To try your own file, [dump a snapshot](/cli/options#snapshot-input) from the Figma Plugin API and open or drop it here. **CLI config** shows the same settings as a [configuration file](/cli/options#cli-configuration-file) for `npx tokens-bruecke@latest`.
