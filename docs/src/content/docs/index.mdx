## How to use

<Steps>

1. Install the plugin from the [Figma Community](https://www.figma.com/community/plugin/1254538877056388290).
2. Run the plugin in any Figma file and adjust the [settings](./plugin/settings/).
3. Download the JSON file or [push it to a server](./plugin/push-to-server/).

</Steps>

A file without variables opens on an empty screen, where you can [import tokens](./getting-started/export-and-import/#import-json--variables) or continue to export styles only.

:::tip[New in v3.23]
Run the plugin in [Dev Mode](./plugin/dev-mode/), and [share a profile in the file](./plugin/profiles/#shared-profiles) so developers export with your settings, without your credentials.
:::

## One converter, three ways to run it

<CardGrid>
  <Card title="Figma plugin" icon="puzzle">
    Pick a color format, include styles, preview the output and download it or push it to
    GitHub, GitLab, JSONBin or your own server.
  </Card>
  <Card title="CLI" icon="seti:shell">
    Export from the Figma REST API or a local snapshot in CI. Pure JSON on stdout for
    scripts and agents.
  </Card>
  <Card title="Library" icon="seti:typescript">
    Call `fetchTokens` and `convertTokens` from your own build pipeline, with no child
    process and no files on disk.
  </Card>
  <Card title="Import" icon="download">
    Bring DTCG tokens back into Figma as variable collections, modes and aliases.
  </Card>
</CardGrid>
